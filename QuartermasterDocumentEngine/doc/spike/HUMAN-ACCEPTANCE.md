## How to run the checks

```bash
cd /home/makc/AI_sandbox/warehouse_solution/QuartermasterDocumentEngine

# 1. List and validate file types
file spike-out/acceptance/*.pdf
ls -la spike-out/acceptance/

# 2. Extract text to count rows / verify Cyrillic
.venv/bin/python - <<'EOF'
from pypdf import PdfReader
for f in [
    "spike-out/acceptance/wb500-typst.pdf",
    "spike-out/acceptance/wb500-weasy.pdf",
    "spike-out/acceptance/fuel-typst.pdf",
    "spike-out/acceptance/fuel-weasy.pdf",
]:
    r = PdfReader(f)
    pages = len(r.pages)
    text = "\n".join(p.extract_text() or "" for p in r.pages)
    print(f"{f}: {pages} pages, {len(text)} chars")
EOF

# 3. Re-render any PDF if needed
```

# Scope: PDF Waybill Template Fix

**Date:** 2026-06-22
**Decision Makers:** пользователь

## Problem

Кладовщик не может полагаться на накладную как на актуальный бумажный отчёт при долгом сборе черновика. Документ либо не обновляется при изменении состава операции, либо рендерится с разрывами при >2 страницах.

## In Scope

1. **Автообновление документа при изменении черновика** — void старого, создание нового с актуальным составом
2. **Корректная пагинация PDF** — таблица не рвётся посередине строки, блоки подписей не разрываются
3. **Сквозная нумерация страниц** — «Лист X из Y» на каждой странице

## Out Of Scope

- Изменение структуры JSON-пэйлоада (он корректен)
- Замена WeasyPrint на другой рендерер
- Шаблоны для типов документов кроме waybill (acceptance_certificate, act — отдельно)
- Поддержка PDF в офлайн-клиентах

## Success Criteria

1. Изменение строк черновика → накладная обновляется (предыдущая версия void)
2. Накладная на 3+ страницах — таблица не рвётся внутри строк, подписи на своих местах
3. «Лист X из Y» — корректный подсчёт

## Assumptions

| Assumption | Status | Validation |
|---|---|---|
| `generate_from_operation()` идемпотентен (можно вызывать повторно) | Validated | Код lines 227-257: для draft void'ит старые и создаёт новый |
| WeasyPrint поддерживает `page-break-inside: avoid` на `<tr>` | Reasonable | Документация WeasyPrint подтверждает |
| Обновление документа при каждом изменении черновика не создаёт проблем с производительностью | Reasonable | Черновики редактируются редко, ~1-5 раз за жизнь операции |

## Alternatives Considered

| Approach | Verdict | Reason |
|---|---|---|
| Do nothing | ❌ | Нарушает ФТ, строка 120 |
| Генерировать документ только по кнопке | ❌ | Не решает проблему актуальности |
| Автообновление в `update_operation()` + фикс CSS | ✅ | Минимальное изменение, покрывает оба бага |

## Selected Approach

1. В `operations_service.py:update_operation()` после успешного обновления → `DocumentService.generate_from_operation()`
2. В `waybill_pdf.html`: `page-break-inside: avoid` на `<tr>`, `<thead>`, `.signature-block`

## First Slice

1. CSS-фикс пагинации (быстрее, видимый эффект)
2. Автообновление документа в `update_operation()`
3. Интеграционный smoke: создать черновик → сгенерировать накладную → изменить строки → проверить что накладная обновилась

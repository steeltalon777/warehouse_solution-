# ADR-0015: Product Name and Branding

## Status
Accepted

## Date
2026-06-19

## Context

Проект «Склад» вырос из внутреннего инструмента в multi-client warehouse framework/WMS. На этапе v3.0 стабилизирован онлайн-клиент (SyncServer + Django + Angular). Версия 3.1 делает разворот к продукту: офлайн-клиенты, брендинг, документация.

Текущее состояние: проект не имеет пользовательского имени. Внутренние имена (`Warehouse Solution`, `SyncServer`, `Warehouse_web`) — технические и не предназначены для конечного пользователя.

Требуется:
- Дать продукту узнаваемое имя
- Не ломать репозитории, сервисы, БД, неймспейсы, Docker-образы, деплой
- Оставить организациям возможность кастомизировать заголовки и логотипы под себя

## Decision

**Продуктовое имя: Quartermaster** (рус. Квартермейстер — должностное лицо, отвечающее за снабжение, имущество, выдачу и контроль).

### Правила

1. **Quartermaster** — пользовательское имя продукта. Используется в:
   - README, документации, ROADMAP
   - Заголовках UI (login, shell, sidebar, footer, page title)
   - ADR и релизных документах
   - Общении с пользователями и заказчиками

2. **Технические имена не меняются.** `SyncServer`, `Warehouse_web`, `Warehouse_frontend`, `Warehouse_client_core`, `WarehouseWorkstation`, Docker-образы, Python-пакеты, .NET неймспейсы — остаются как есть.

3. **Организации кастомизируют брендинг.** Quartermaster — это фреймворк/WMS. Конкретная организация может заменить название и логотип через конфигурацию. Система не навязывает жёсткий брендбук.

4. **Брендинг конфигурируется**, а не хардкодится. Переменные окружения / настройки:
   - `APP_PRODUCT_NAME` (по умолчанию: `Quartermaster`)
   - `APP_PRODUCT_VERSION`
   - `APP_PRODUCT_TAGLINE`
   - `APP_BRAND_LOGO`
   - `APP_BRAND_FAVICON`
   - `APP_BRAND_PRIMARY_COLOR`

## Consequences

- Пользователи видят «Quartermaster» в интерфейсе, документации, коммуникациях.
- Разработчики и агенты продолжают работать с техническими именами (`SyncServer`, etc.) — никакой ломки.
- Организации могут ребрендировать продукт под себя без форка кода.
- ADR фиксирует решение, чтобы новые агенты не предлагали «переименовать репозитории для консистентности».

## Confidence
**High** — продукт получает имя без разрушения существующей инфраструктуры.
